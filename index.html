How prices update. Every morning a scheduled job pulls current prices from the eBay Browse API and the Best Buy Products API and republishes this page. Listings marked “Updated” came from that job. Amazon, Newegg, Micro Center and Alibaba don't offer free price APIs, so their prices are estimates from Oct 5, 2026. Use the product links to check those stores' current prices.

About these prices. Starting figures are typical prices compiled on Oct 5, 2026 from public price trackers and store search results. RAM prices rose sharply in 2026 and move weekly, so treat these as a guide and confirm on the store page before you buy. "View on" links go straight to the product page (eBay links go to its catalog page, which lists every seller of that exact part). A "Search" link is used where no product page could be confirmed, and for Alibaba, whose listings change daily. GPU links go to the MSI Ventus version of each card.

Performance index: GPUs use average 1080p raster results (RTX 4060 = 100); CPUs use average gaming results (5700X = 100); RAM uses true latency (10 ns = 100). Images are illustrations, not product photos.
